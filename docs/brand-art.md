# 저만치 최종 로고

2026-11-01 사용자가 확정한 ‘같은 궤도’ 단순화안이다. 열린 원형 길의 반대편에 흰 황새와 회색 그림자가 떨어져 걷는다. ‘저만치 멀리 떨어진 나와 비슷한 너를 만나고 싶어’라는 의미를 두 존재 사이의 거리와 여백으로 표현한다.

나뭇잎·글씨·거친 선을 제거하고 원과 두 황새의 윤곽을 굵게 정리했다. 마지막 수정으로 그림자의 다리와 발도 몸통과 같은 회색으로 통일했다. 승인된 원본은 `orbit-simple-v3.png`이며 PNG는 원본 바이트 그대로 보관한다.

- 원본 PNG: `public/assets/brand/jeomanchi-symbol.png`, 1254×1254, 승인된 아이보리 배경 포함.
- PNG SHA-256: `07ae1cc7a3bf217af5a002f5c91ca7bb228d375355db41fec6a745377339f5e2`.
- SVG 호환 파일: `jeomanchi-symbol.svg`는 승인된 PNG를 내장한 SVG 컨테이너다. 편집 가능한 벡터 패스로 재구성한 파일은 아니다.
- 파비콘: `favicon.svg`는 256px PNG를 내장하며, `favicon-16.png`, `favicon-32.png`, `favicon-256.png`도 제공한다.
- ICO: `public/favicon.ico`, 16/32/48/256px PNG 프레임.
- 홈 화면 아이콘: `apple-touch-icon.png`, 180×180.
- 캐시 버전: `orbit-final-20261101`.

시안 생성·단순화·색상 수정에는 built-in image_gen을 사용했고, PNG/ICO 크기·형식 변환에는 Sharp를 사용했다. 새 로고는 파비콘/ICO와 다운로드 파일에만 적용한다. 게임 상단과 결과 카드의 기존 글자·배치는 유지한다.
